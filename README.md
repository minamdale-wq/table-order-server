# 테이블 오더 미니 서버 설치 안내

매장 컴퓨터 한 대에서 서버를 켜 두면, 태블릿 7대가 같은 와이파이로 접속해 주문을 주고받습니다.
**인터넷과 Claude 계정이 없어도 됩니다.** 필요한 것은 같은 공유기(와이파이)뿐입니다.

```
 [주문용 태블릿 1~6]  ──┐
                        ├── 매장 와이파이(공유기) ── [서버 컴퓨터: 이 프로그램]
 [주문받는 태블릿 7] ───┘
```

---

## 1. 서버 컴퓨터 준비

- 윈도우 PC, 맥, 미니PC, 라즈베리파이 모두 됩니다. 남는 노트북이어도 괜찮습니다.
- **항상 켜 둘 수 있는 기기**여야 합니다. 서버가 꺼지면 주문도 멈춥니다.
- 매장 공유기에 랜선이나 와이파이로 연결합니다. 랜선 쪽이 더 안정적입니다.

## 2. Node.js 설치 (처음 한 번)

1. https://nodejs.org 에 들어가 **LTS** 버전을 내려받아 설치합니다. 설치할 때는 모두 '다음'을 눌러 기본값 그대로 두면 됩니다.
2. 이 프로그램은 Node.js만 있으면 돌아가고, 다른 것을 추가로 설치할 필요가 없습니다.

## 3. 프로그램 넣기

압축을 풀어 생긴 `table-order-server` 폴더를 바탕화면이나 문서 폴더처럼 찾기 쉬운 곳에 둡니다.

## 4. 서버 켜기

- **윈도우**: `start-windows.bat`을 더블클릭합니다.
  - "Windows 방화벽" 창이 뜨면 **개인 네트워크**에 체크하고 **액세스 허용**을 누릅니다. 이걸 허용하지 않으면 태블릿이 접속하지 못합니다.
- **맥**: `start-mac.command`를 **오른쪽 클릭 → 열기**로 엽니다. 처음 한 번은 경고가 나오는데, 그때 '열기'를 누르면 됩니다.
  - "들어오는 네트워크 연결을 허용할까요?"가 뜨면 **허용**을 누릅니다.

검은 창에 아래처럼 주소가 나오면 성공입니다. **이 창은 닫지 마세요.**

```
  주문받는 태블릿 :  http://192.168.0.10:8765/#t7
  주문용 태블릿   :  http://192.168.0.10:8765/#t1  ~  #t6
```

프로그램이 멈추더라도 시작 파일이 5초 뒤 자동으로 다시 켭니다.

## 5. 태블릿 연결

모든 태블릿을 서버 컴퓨터와 **같은 와이파이**에 연결한 뒤 크롬 같은 브라우저로 주소를 엽니다.

| 기기 | 열 주소 (예시) |
|---|---|
| 주문받는 태블릿 | `http://192.168.0.10:8765/#t7` |
| 주문용 1번 | `http://192.168.0.10:8765/#t1` |
| 주문용 2~6번 | 주소 끝만 `#t2` … `#t6` 으로 바꿈 |

1. **주문받는 태블릿을 먼저** 엽니다. 처음에는 "관리 PIN 만들기" 화면이 나옵니다. 숫자 4~6자리를 정하세요.
   - 이 PIN은 메뉴 수정, 정산, 설정 같은 관리 기능과 고객 화면 숨김 메뉴에 쓰입니다.
   - 잊어버렸을 때는 이 안내서 9번을 보세요.
2. 주문용 태블릿은 주소를 열기만 하면 바로 고객 화면이 나옵니다.
3. 각 태블릿에서 브라우저 메뉴의 **홈 화면에 추가**를 해 두면 다음부터 아이콘으로 열 수 있습니다.
4. 고객이 다른 화면으로 나가지 못하게 태블릿의 **화면 고정(앱 고정, 키오스크 모드)** 기능을 켜 주세요.

처음 설치하면 태블릿 7대(주문용 1~6, 주문받는 태블릿)와 '확인 필요' 목록이 기본으로 들어 있습니다.
메뉴는 비어 있으니 주문받는 태블릿의 **메뉴 관리** 탭에서 입력하세요.

## 6. 꼭 해 둘 설정

- **서버 컴퓨터 IP 고정**: 공유기 관리 화면의 'DHCP 고정 할당(주소 예약)'에서 서버 컴퓨터에 항상 같은 IP를 주세요. IP가 바뀌면 태블릿에 저장한 주소로 접속이 안 됩니다.
- **절전 끄기**: 서버 컴퓨터가 잠들지 않게 '절전 모드 사용 안 함', '디스크 끄기 안 함'으로 설정합니다. 맥은 시작 파일이 실행 중일 때 잠들지 않게 처리되어 있습니다.
- **윈도우 자동 업데이트 재부팅**: 영업시간에 재부팅되지 않도록 '사용 시간'을 영업시간으로 맞춰 둡니다.
- **손님 와이파이 분리(권장)**: 손님이 쓰는 와이파이와 매장 기기용 와이파이를 나누면 더 안전합니다. 같은 와이파이를 쓰더라도 관리 기능은 PIN으로 막혀 있습니다.

## 7. 컴퓨터를 켤 때 자동으로 서버 시작

- **윈도우**
  1. `Win + R`을 누르고 `shell:startup`을 입력한 뒤 확인을 누릅니다.
  2. 열린 폴더에 `start-windows.bat`의 **바로 가기**를 넣습니다. 시작 파일을 오른쪽 클릭 → 바로 가기 만들기 → 그 폴더로 옮기면 됩니다.
- **맥**: 시스템 설정 → 일반 → 로그인 항목 → `+` → `start-mac.command`를 추가합니다.
- **라즈베리파이·리눅스**
  1. 폴더를 `/home/pi/table-order-server`에 둡니다.
  2. `table-order.service`를 `/etc/systemd/system/`에 복사합니다.
  3. `sudo systemctl enable --now table-order`를 실행합니다.

## 8. 데이터와 백업

- 모든 데이터는 프로그램 폴더 안의 **`data` 폴더**에 저장됩니다. 주문, 메뉴, 설정, 올린 동영상·사진이 다 여기 있습니다.
- 서버가 매일 `data/backups`에 자동 백업을 남기고 60일치를 보관합니다.
- 컴퓨터 고장에 대비해 가끔 `data` 폴더를 통째로 USB나 클라우드에 복사해 두세요.
- 주문받는 태블릿의 **설정 → 지금 백업 내려받기**로 그 자리에서 백업 파일을 받을 수도 있습니다.
- 다른 컴퓨터로 옮길 때는 프로그램 폴더 전체를 `data` 폴더까지 함께 복사하면 그대로 이어집니다.

## 9. 문제 해결

| 증상 | 해결 |
|---|---|
| 태블릿에 "미니 서버에 연결되지 않습니다" | 서버 창이 켜져 있는지, 태블릿과 서버가 같은 와이파이인지, 방화벽을 허용했는지 확인 |
| 주소를 열어도 아무것도 안 나옴 | 서버 창에 표시된 IP가 바뀌었는지 확인 (6번 IP 고정) |
| 서버 창에 "포트 8765을 이미 쓰고 있습니다" | 서버가 이미 켜져 있는지 확인. 다른 프로그램이 쓰고 있다면 시작 파일 안의 `node server.js` 앞에 `set PORT=8766 &&`(윈도우) 또는 `PORT=8766`(맥)을 붙이고, 태블릿 주소도 그 번호로 바꿈 |
| 관리 PIN을 잊어버림 | `data` 폴더 안에 `reset-pin.txt`라는 빈 파일을 만들고 서버를 다시 켜면 PIN이 지워짐. 그 뒤 주문받는 태블릿에서 새로 만들면 됨 (주문·메뉴 데이터는 그대로) |
| 주문 알림 소리가 안 남 | 주문받는 태블릿 화면 위의 '알림음 켜기'를 한 번 누름 (브라우저 정책상 한 번은 눌러야 함) |

## 10. 업데이트

**주문받는 태블릿 → 설정 → 프로그램 업데이트 → 업데이트 확인**을 누르세요.
새 버전이 있으면 **지금 업데이트**를 누르면 됩니다.

- 서버가 새 버전을 GitHub(github.com/minamdale-wq/table-order-server)에서 받아 스스로 바꾸고, 필요하면 저절로 다시 켜집니다.
- 주문용 태블릿은 장바구니가 비어 있을 때 저절로 새로고침됩니다.
- 문제가 생기면 **이전 버전으로 되돌리기**를 누르세요. 바꾸기 전 버전은 `data/versions`에 최근 10개까지 보관됩니다.
- 업데이트할 때만 서버 컴퓨터가 인터넷에 연결돼 있으면 됩니다.
- 서버를 시작 파일(`start-windows.bat`, `start-mac.command`)로 켜야 업데이트 뒤 자동으로 다시 켜집니다.
- 주문·메뉴·동영상이 들어 있는 `data` 폴더는 업데이트해도 그대로 남습니다.

### 참고: 이 버전에서 달라진 점 (claude.ai 버전과 비교)

- Claude 계정 로그인과 인터넷이 필요 없습니다.
- 동영상 파일 크기 제한이 파일 하나당 최대 2GB로 커졌고, 올릴 때 진행률이 표시됩니다.
- 태블릿 연결 끊김은 서버가 직접 감지해 기록합니다. 주문받는 태블릿 화면이 꺼져 있어도 기록되고, 서버 컴퓨터가 꺼져 있던 시간도 남습니다.
- 태블릿 시계가 틀려도 주문 시각은 서버 컴퓨터 시계를 기준으로 맞춰집니다.
- CSV는 파일로 내려받아 엑셀에서 바로 열 수 있습니다.
- 관리 PIN은 서버가 확인합니다. PIN 없이는 메뉴·가격·정산·설정을 바꿀 수 없습니다.
